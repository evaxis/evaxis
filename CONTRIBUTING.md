# Contributing

Follow the [shared Evaxis contribution workflow](https://github.com/evaxis/.github/blob/main/CONTRIBUTING.md)
and [code of conduct](https://github.com/evaxis/.github/blob/main/CODE_OF_CONDUCT.md).

This repository is documentation and planned contracts only. Hydrate its local
cARL governance, define the scoped PR contract, preserve all independence and
security invariants, validate changes and reconcile memory/docs before review.
Use a feature branch and PR after bootstrap; never bypass protections.

Do not add implementation, invented schemas/findings/tests, a build system,
provider dependency or licensing terms without explicit approval. Licensing and
contribution-rights terms remain undecided; discuss substantial work first.
No product build/test runner exists. Governance diagnostics and CI validate
cARL, not product capabilities. Report vulnerabilities [privately](SECURITY.md).
