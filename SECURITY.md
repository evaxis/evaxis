# Security reporting

Evaxis is in the foundation/design stage. No released versions or production
services exist here.

Use [private vulnerability reporting](https://github.com/evaxis/evaxis/security/advisories/new)
under **Security -> Report a vulnerability**. Do not report vulnerabilities in
public issues or PRs. If the private form is unavailable, contact the owner
through [their GitHub profile](https://github.com/goldjg) to arrange a private channel.

Provide affected paths/commits, expected impact and a minimal non-sensitive
reproduction. Never submit live credentials, customer evidence, tenant details
or personal information. Coordinate disclosure; no SLA or bounty is promised.
See the [shared policy](https://github.com/evaxis/.github/blob/main/SECURITY.md).
